# 生产流程的选择与继承

2026-10-06，用户指出当前制作仍像从零设计，四个项目没有成为实际生产基础。核对发现：已有完整的自有口播渲染链，但上游实际代码适配主要为 TalkCraft 的选卡函数及 title-demote-to-label 时间调度；检索覆盖数量不能代表生产能力继承数量。

2026-10-07，用户将柱子哥农场参考片的剪辑模式确认为所有口播的默认模式。口播的画面和动作以 [口播剪辑方法](talking-head-editing-method.md) 中的参考为准；上游提供成熟实现，不替代这个视觉目标。不增加风格包、风格选择或新的中间层，直接在现有口播流程中落实。

## 三条流程的生产基础

| 主流程 | 应继承的生产基础 | 当前实际接通情况 |
| --- | --- | --- |
| talking-head | TalkCraft 的内容/时间、SHOTBOOK、原生镜头组件和渲染流程 | 三项原生 TSX、八个自有场景已接外部实例和公共预览；参考复建及手机原片代表段已获认可；完整自动流程未接通 |
| product-promo | ShotCraft 的卖点到镜头、原生镜头实现与产品素材运镜 | 目前提供源码和参考检索；生产适配未接通 |
| knowledge-explainer | Anything2Explainer 的文稿、配音、分镜、图元、成片结构和渲染 | 目前整理了少量成品参考；生产适配未接通 |
| 可选组件资产 | ThreeUI 中实际选中的组件 | 目前为来源入口；不承担主流程 |

AwesomeOpus 提供额外案例，不改变以上生产基础。

## 新制作采用的选择顺序

1. 根据内容选择一条主流程。口播先按农场参考分析本期的对象、信息组织与动作，再读取对应上游的 Skill、项目模板、相关原生组件和成品，选择能实现该目标的代码；产品宣传和知识讲解沿用各自生产基础。
2. 优先保留该流程成熟的内部结构和动画实现。在仓库外准备运行实例，代码吸收到自有 workflow/library 时记录准确来源。依赖与单期产物继续放在仓库外，不修改子模块。
3. 需要接入新实现时，检查与该实现直接相关的运行能力和真实产物，保留成熟动作结构。口播按默认模式适配内容、原画幅和人物构图，不为验证卡片另加一条视频制作任务，不以重复审美重渲代替实现分析。
4. 修改本期文案、素材、参数和确有冲突的部分。上游某一作者的固定配色、人物裁切、底板、品牌署名和审查要求不自动升级为本项目规则，用户约束优先。
5. 成熟实现确实缺少所需表达时，再在现有 workflow/library 中补充所需代码，并记录具体缺口。明确区分成熟代码复用、原生流程接通与自有实现，不把这些状态混称为已继承上游。口播以实现参考中的画面和动作推进，不以接通任意卡片代替视觉目标。

Winter Agent 统一项目目录、来源、状态、工具调用、反馈和交付。内容标注、候选检索与施工记录可以继续使用；执行配置保留所选 workflow 的原生结构，不要求三条流程都转换为 progressive-explanation 图层。

当前自有口播配方保留已交付案例、续作和局部补充用途。它有可用的执行能力，但不作为上游流程已接通的证明，也不继续扩张为三条生产线共同的视觉引擎。

## 当前阶段

农场参考的画面与动作分析已进入直接实现：现有 Remotion 入口接入人物介绍、指标比较、证据入场、观点盖章、开发时间、数据库关系和温度告警七个场景。开发时间将大结论、三个工作节点和双日期时间线放在一个累积场景内；日历间隔从日期计算，与开发投入分开表达。数据库关系按分类建立、连线转绿、结果补入推进，跨底片切换保持状态。温度段把读数、色条揭示和超限颜色联动，接着补风险与人工/自动处理说明；参考色条是示意揭示，不作为等比例仪表。可准备交互实例，或按授权生成带原声的同步对照预览。分析与校准文件在仓库外的参考项目中。4:3原片已接入计数/流程窄布局、原生应用逐项聚焦和单主证据预览，布局按本期前倾人物及浅背景适配，用户已认可为 [参考迁移可用里程碑 v1](milestone-talking-head-reference-v1.md)。准确字体、其余场景和全片编排仍需继续完成，不宣称已经自动复刻。规则调整本身不触发新的样片或全片渲染。

此前三项 TalkCraft 原生镜头的手机口播试跑保留为技术接入记录，不作为新的视觉基准。执行入口见 [原生 TalkCraft](../skills/winter-video-agent/references/native-talkcraft.md)。后续仅在它们能实现目标动作时复用，不以检索条目数量或样片产出数量当作接通程度。
