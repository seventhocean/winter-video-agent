# 口播视频风格规范 v0.1（候选）

状态：首轮样片未通过用户审阅，仍属候选。2026-10-02，用户评价 Nginx `style-study-v3.mp4` 与示例差距很大、像随便摆放素材。当前参数和版式不得作为已验证默认风格。本文是 `talking-head` 的候选设计方法，不是其他两条流程的视觉规则。当前用于 4:3 Nginx 口播风格验证；该项目采用无覆盖遮罩，不把这一选择自动应用于其他项目。

2026-10-06，用户确认需要沉淀的是剪辑逻辑。今后的制作入口采用 [参考驱动的口播剪辑方法](talking-head-editing-method.md)；本文保留为历史试验记录，下列风格与数值不提升为默认模板。

## 风格目标

让观众在口播持续进行时，清楚看见「现在解释的对象、它与其他对象的关系、这一句带来什么新信息」。密度来自信息按层次累积、真实证据和前后镜头的接力，不来自同时出现的元素数量。

## 稳定语法与单片变量

| 范围 | 候选规则 | 单期需要决定的内容 |
| --- | --- | --- |
| 主体 | 一个语义拍只有一个主要注意目标；次要对象维持同一坐标体系 | 人物、证据或图解谁先担任主体 |
| 层级 | 标题、对象名、关系说明、来源/注脚、字幕各有稳定字号级差与位置 | 画幅、人物位置、原有字幕位置 |
| 颜色 | 一支视频先选择一个主要强调色；警示/成败色只有语义确实需要时出现 | 品牌色、素材自身的色温与对比度 |
| 动作 | 新概念落入已有结构，关系随后显现；对象移动必须表达交接、比较或结果 | 节奏快慢、动效强度、具体时长 |
| 证据 | 页面、终端、操作来自真实素材；概念插画明确作为示意 | 能获得的原片、截图及隐私处理 |
| 连续性 | 镜末保留一个可识别的对象、方向或问题，接到下一镜 | 转场是否换场景、是否保留人物 |

本次 4:3 样片的**试用参数**：画布 1280×960、30 fps；原片上下黑边分别用于章节导航和字幕，正文只占活动画面中的人物对侧；暖白字 `#F5F7F4`、薄荷青 `#73E6CE` 为主要强调、灰青 `#B5C9C9` 为说明。这里的数值是当前项目的选择，不是全局品牌色。对象先后出现可相隔约 0.12–0.25 秒；完整句子出现后须留阅读时间，不能把运动密度当成信息密度。

## 编排决策表 v0.1

每个语义拍先记录 `口播功能 / 信息关系 / 证据情况 / 人物位置 / 新出现的意义`，再选画面。一个镜头可以跨几句话；句末不要求机械换镜。

| 条件 | 默认打法 | 避免的误读 |
| --- | --- | --- |
| 具体对象从 A 到 B，当前是解释机制 | 保留 A、B 的固定位置；对象或路径依次出现；最后突出关系 | 示意运动不能冒充操作已经完成 |
| 同一对象有两种用途或模式 | 对象与连接保持稳定；切换标签、指向和载荷 | 两种模式不能画成必须依次完成的步骤 |
| 有真实页面、终端或操作 | 让原素材成为主体；用少量定位文字指出正在看哪里 | 生成画面不能冒充真实软件截图 |
| 并列项 | 共用基线/尺寸与顺序；逐项点亮 | 并列不等于进度或成功率 |
| 可比数字 | 数字与单位在同一层级；比较条有共同尺度和来源 | 不相关数字不能共用长度暗示比例 |
| 观点或结论 | 减少图解，让人物或一句明确结论承担主体 | 不为填满画面而引入无关物件 |

## 逐镜施工单最少写清

时间与口播原话；这一镜要观众理解什么；功能、关系和证据；人物/字幕保护区域；所选组件与来源；镜内新信息的顺序和停留；上一镜留下什么、下一镜接什么；是否有未解决的素材或事实缺口。

## 审阅问题

先看一段新素材的结果：语义是否清楚、画面是否有统一的主次、真实素材是否充分、动作是否有表达意义、人物和字幕是否舒适。样片没有获得用户认可前，不把本规范标为已验证，也不把单期反馈升级成全局规则。
